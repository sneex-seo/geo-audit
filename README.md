# GEO Audit

Аудит готовності сайту до AI-пошуку (GEO, Generative Engine Optimization):
- чи можуть сайт прочитати AI-краулери;
- чи зручно цитувати його в ChatGPT, Perplexity, Google AI Overviews і Copilot;
- чи вистачає на ньому сигналів довіри.

Біля кожного зауваження є доказ із сайту, пояснення, блоки «Як зараз» і «Як треба», готовий код і спосіб перевірити виправлення.

Приклад звіту: https://oleksiimatuznyi.com/lab/geo-audit/

## Що перевіряє

Загальний бал 0-100 - зважена сума дев'яти категорій. Якщо категорію не вдалося оцінити, наприклад сайт закрився від бота, звіт позначає бал як неповний.

| Категорія | Що перевіряє | Вага |
|---|---|---|
| Цитованість контенту | обсяг, абзаци-відповіді, заголовки, вступ «спершу відповідь», списки й таблиці, факти й цифри, свіжість, title і description | 20% |
| Доступ AI-ботів та індексація | robots.txt за правилами Google для пошукових і навчальних AI-ботів, блокування за User-Agent на рівні захисту сайту, meta robots і X-Robots-Tag | 14% |
| E-E-A-T сигнали | сторінка «Про нас» або «Про мене», контакти, юридичні сторінки, реквізити, авторство й дати статей, відгуки, маркери довіри | 14% |
| Структуровані дані | синтаксис JSON-LD, сутність організації або людини, WebSite, BreadcrumbList, розмітка під тип сайту | 12% |
| Сутність бренду | Wikidata, Вікіпедія, профілі в sameAs, узгодженість назви | 12% |
| Рендеринг та індексованість | чи є контент у сирому HTML без JavaScript, canonical, мова сторінки, hreflang, коди відповіді | 10% |
| Технічна база | HTTPS і редиректи, TTFB, стиснення, Core Web Vitals (PageSpeed Insights і CrUX), soft-404 | 10% |
| XML-карта сайту | пошук карти, валідність, lastmod, коди відповіді URL із карти | 5% |
| llms.txt | наявність і структура за пропозицією llmstxt.org | 3% |

Тип сайту визначається автоматично: магазин, локальний бізнес, медіа, SaaS, послуги, корпоративний або особистий сайт експерта. Від типу залежать вимоги й рекомендована розмітка. Аудит дивиться головну і до 4 внутрішніх сторінок.

AI-висновок наприкінці (Claude від Anthropic) необов'язковий: короткий підсумок, оцінка E-E-A-T і контенту, пріоритети й тестові запити для ручного моніторингу видимості в AI. Без ключа Anthropic усі дев'ять перевірок працюють, а AI-висновку у звіті просто немає.

## Запуск

Потрібен PHP 8.4+ з розширеннями curl, dom, mbstring, pdo_sqlite і openssl.

```bash
git clone https://github.com/sneex-seo/geo-audit.git
cd geo-audit
php -S 127.0.0.1:8080
```

Відкрийте http://127.0.0.1:8080, вставте адресу сайту і натисніть «Запустити аудит». Аудит триває 1-2 хвилини, прогрес видно на сторінці звіту. Звіт можна зберегти в PDF.

Ключі необов'язкові:

```bash
cp .env.example .env          # Windows: copy .env.example .env
```

- `ANTHROPIC_API_KEY` - AI-висновок у кінці звіту;
- `PAGESPEED_API_KEY` - Google API-ключ для PageSpeed Insights і CrUX. Без нього PageSpeed працює зі спільною квотою, яка часто вичерпується.

## Командний рядок

Аудит без веб-інтерфейсу і бази, результат у JSON:

```bash
php dev/run.php https://example.com --no-ai --progress > report.json
```

HTML-звіт із цього JSON:

```bash
php dev/render.php report.json report.html web
```

## Сервер

- На публічному сервері задайте `GEO_AUDIT_USER` і `GEO_AUDIT_PASSWORD` у `.env`. Без них будь-хто зможе запускати аудити від імені вашого сервера і витрачати ваш ключ Anthropic.
- Дані (база SQLite, звіти, логи) лежать у `data/`. Apache закриває цю папку через `.htaccess`. nginx файли `.htaccess` ігнорує, тому там винесіть дані за межі webroot через `GEO_AUDIT_DATA`.
- Аудит запускається фоновим процесом PHP: на Linux і macOS через `nohup`, на Windows через `start`.

## Обмеження

- Сайти із захистом від ботів можуть віддати сторінку перевірки замість контенту. Тоді аудит пробує User-Agent відомих AI-ботів, а якщо й це не допомагає, ставить неповний бал.
- Тип сайту визначається евристиками. Якщо він визначився неправильно, частина вимог буде нерелевантною.
- llms.txt - неофіційна пропозиція, тому його вага мала, а зауваження мають низьку важливість.
